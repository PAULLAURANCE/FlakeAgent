# FlakeAgent
本仓库实现 FlakeAgent，一种用于 Flaky Test 自动复现与根因诊断的闭环大语言模型智能体。系统从冷启动开始，仅需测试标识和项目源代码，通过“规划—执行—观察—反思”循环，自动尝试测试顺序扰动、同 JVM 重复执行、睡眠注入、资源压力、环境操控和 NonDex 非确定性注入等 12 类策略。复现成功后，系统输出波动类别、根因假设及对应的文件—行号证据。仓库包含工具实现、ReproFlake 基准清单、执行日志、成本记录和结果复现实验脚本，可用于 Flaky Test 的自动化研究与 CI 调试。论文在 92 个测试上实现 47.8% 的失败复现率，类别判断准确率达 86.4%。
